# PANC Quest — Você comeria essa planta?

Site educativo de Ciências para conhecer Plantas Alimentícias Não Convencionais, biodiversidade e cuidados de identificação.

## Conteúdo

- Cinco fichas educativas de PANCs
- Quiz interativo com 10 perguntas
- Explicações depois de cada resposta
- Pontuação e recorde salvo apenas no aparelho
- Funcionamento offline depois do primeiro acesso
- Fontes técnicas da Embrapa e do Ministério da Saúde

## Publicação

O projeto é estático e pode ser publicado diretamente pelo GitHub Pages a partir da raiz da branch `main`.

## Segurança

As fotografias são referências educativas. Nenhuma planta deve ser consumida sem identificação segura e orientação de pessoa capacitada.
